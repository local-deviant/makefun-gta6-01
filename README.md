GOLDEN TIDE 3D — an open-world crime game in 3D. Drive and steal cars across the island city of Costa Dorada (8 named districts), run 7 story missions with named characters and portrait dialogue, race 3 street circuits against named rivals, and outrun the police through a 1–5 star wanted system (cruisers, roadblocks, helicopter searchlight). Dense HUD with mission tracker, police unit list, radio, respect, minimap + GPS. Built with vendored three.js (WebGL), no network, deterministic.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
python3 -m http.server --directory game 8080
# open http://localhost:8080
```
